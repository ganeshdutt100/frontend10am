4. Nested if-else Questions
Write a program to check whether a person is eligible to vote. If eligible, then check whether they are eligible for a senior citizen benefit.

Write a program to check whether a student has passed. If passed, then check whether the student has received Distinction (marks ≥ 75).

Write a program to check whether a number is positive. If positive, then check whether it is even or odd.

Write a program for login:
First check whether username is correct.
If username is correct, then check the password.
Display "Login Successful" only when both are correct.

Write a program to check eligibility for a job:
First check whether age is 18 or above.
If eligible by age, check whether qualification is "B.Tech".
If both conditions are satisfied, display "Eligible".

Write a program to check whether a student passed in Maths. If passed, then check whether they also passed in English.

Write a program to check whether a person can enter a movie:
First check whether age is 18 or above.
If eligible, check whether they have a valid ticket.
Display "Entry Allowed" only if both conditions are true.
